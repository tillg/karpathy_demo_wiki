# Topological space (Wikipedia)

*Source: https://en.wikipedia.org/wiki/Topological_space (accessed 2026-10-02). Summarised in own words.*

A **topology** on a set X is a collection τ of subsets of X, called the **open sets**, that obeys three rules:

1. The empty set and X itself are open.
2. Any union of open sets — finitely or infinitely many — is open.
3. The intersection of finitely many open sets is open.

The pair (X, τ) is a topological space. The rules are deliberately weak, so the same set can carry very different
topologies:

- **Discrete topology:** every subset is open. Points are maximally "separated"; a sequence converges only if it is
  eventually constant.
- **Trivial (indiscrete) topology:** only the empty set and X are open. Nothing can be told apart; every sequence
  converges to every point.
- **Standard topology on the real line:** generated by open intervals (a, b). More generally, any metric space gets
  a topology whose basic open sets are the open balls.

**History.** Felix Hausdorff gave the first definition of a topological space in 1914 in *Grundzüge der
Mengenlehre* (Principles of Set Theory).

**Continuity.** With open sets in hand, continuity needs no distances: a map f: X → Y is continuous if the
preimage of every open set of Y is open in X. For maps between real numbers this agrees with the familiar
epsilon–delta definition.

**Homeomorphism.** A homeomorphism is a bijection f that is continuous and whose inverse is also continuous. Two
spaces connected by a homeomorphism are, from topology's point of view, the same space with different labels — every
topological property of one holds for the other.

Note to self: the definition never mentions "nearness" directly. Open sets *are* the notion of nearness — a set is
open when it contains, around each of its points, a little room to move.

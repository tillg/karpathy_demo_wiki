# karpathy.app demo vault

Example vault for [karpathy.app](https://karpathy.app): an LLM-maintained personal knowledge base.
`Sources/` holds the raw material, `Wiki/` the pages the AI writes from it. Open it in Obsidian or attach it in
karpathy.app.

Topics so far: **mountains** (ski tours, hikes, via ferratas, safety), **coffee** and **mathematics / topology**.
Web sources are summarised in our own words and link to the original page.

**All content is example data.** Tours, altitudes and seasons are approximate and only here to show how the app
works. Mountain pages are not route, snow or avalanche advice — check current conditions and a guidebook before going.

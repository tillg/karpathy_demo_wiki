# Hairy ball theorem

**Statement:** an even-dimensional sphere has no continuous tangent vector field that is nowhere zero. On a hairy
ball there is always a cowlick.

- [[henri-poincare]] proved it for the ordinary 2-sphere (1885), [[luitzen-brouwer]] for all even dimensions (1912).
- **Why:** it comes down to the [[euler-characteristic]] — the sphere has χ = 2, so any field must vanish somewhere;
  the torus has χ = 0 and *can* be combed.
